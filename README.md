# Still Home Cleaning

Static website for Still Home, a home-cleaning service in Metro Vancouver.

The public website is served from `/stillhome/`. The root page redirects visitors there. The site includes service information, scroll animations, and an estimate calculator that runs locally in the visitor's browser.

Deploy the repository root with GitHub Pages. `CNAME` sets the custom domain to `services.synapses.cloud`, and `.nojekyll` keeps the static files unchanged.
